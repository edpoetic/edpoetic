# Administrative SOP: Document Control
**DEMONSTRATION SAMPLE**

## Purpose
Keep shared business documents easy to find, identify, and maintain.

## Procedure
1. Save files in the approved shared folder.
2. Use naming convention: YYYY-MM-DD_Department_DocumentName_v01.
3. Use consistent date and currency formats.
4. Set access based on role; do not share sensitive files publicly.
5. Record owner, last updated date, and review status in the document register.
6. Archive superseded versions rather than silently overwriting records.
7. Review the register weekly.

## Document register fields
Document ID | File name | Owner | Last updated | Version | Status | Link

## Quality checklist
- Correct folder and permissions
- Clear file name and version
- Required fields complete
- No duplicate active versions

*Sample SOP; adapt to each client's policies.*
